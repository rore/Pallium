## Summary

Keep Pallium focused on durable, cited, derived knowledge that can be returned to an agent as high-signal context.

## Why

This is one of the clearest long-term value propositions for the project, but it still needs the lower-level core and retrieval foundations before it can become concrete roadmap work.

## In Scope

- durable memory objects with clear supporting evidence
- retrieval packaging aimed at high-signal agent context
- staying generic enough to serve more than one agent workflow

## Out of Scope

- turning Pallium into an agent runtime
- replacing source retrieval from external systems
- making one internal team use case the project's only identity

## Done When

1. The idea is concrete enough to split into one or more committed feature items.
2. Its scope can be expressed without collapsing the generic-core boundary.
