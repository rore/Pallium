# Roadmap

## Phase 0 - Context and design

- capture vision and architectural principles
- define core abstractions
- define semantic-layer boundaries
- define API contracts

## Phase 1 - Minimal core

- implement source item persistence
- implement annotations and memory objects
- implement relation and index primitives
- expose basic write and read APIs

## Phase 2 - First semantic layer

- add one reference semantic layer
- define a minimal typed memory schema contract
- implement promotion from annotation to durable memory object
- support compact evidence-backed retrieval

## Phase 3 - Retrieval quality

- improve structured retrieval
- add lexical ranking
- add optional embedding provider support
- improve result packaging

## Phase 4 - Tiered memory extension

- add bounded consolidation jobs
- produce higher-level memory objects
- include consolidated objects in retrieval
