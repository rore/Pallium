# Upstream field feedback

This Hermes package does not expose a Pallium field-feedback submission tool. If a repeatable product or integration defect occurs, report it through the user's normal approved channel. Do not post private prompts, transcripts, injected or retrieved memory, credentials, repository names, local paths, identifiers or logs. A memory-quality miss belongs to Pallium's existing feedback and replay mechanisms when those are available; it is not a Relay send or work-association operation.
